# 🃏 Python Blackjack

A terminal-based Blackjack game written in Python that supports a human player (Player 1) competing alongside an automated player (Player 2) against the house dealer.

#### ✨ Key Features
* **Multi-Hand Support:** Simulates a round with Player 1 (you), Player 2 (automated AI), and the Dealer.
* **Smart Ace Handling:** Automatically adjusts the value of Aces (from 11 down to 1) if a hand's total exceeds 21.
* **Automated Opponent:** Player 2 runs on a built-in decision logic loop to hit or stand based on the dealer's visible card and its own total.
